# Verity Channels

A standalone frontend prototype for the Verity Channels website.

## Run
Open `index.html` in a browser, or serve this folder with any static web server.

## Included
- Verity-branded landing page
- Public Channels directory
- Search and category filters
- Channel view and posting UI
- Create-channel modal
- Responsive mobile layout

## Important
This version is a frontend prototype. Channel data is stored in browser memory and is not yet shared between real users.

## Production next step
Connect the UI to a real backend for:
- accounts/authentication
- persistent channels and posts
- real-time messaging
- channel permissions
- image/file uploads
- notifications
- moderation
- Verity AI integration
